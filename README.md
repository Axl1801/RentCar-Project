-- Descripción --

Este proyecto consiste en el diseño de una interfaz para un sistema de renta de vehículos. Permite gestionar clientes, vehículos y rentas mediante una interfaz intuitiva enfocada en la experiencia de usuario (UI/UX).

-- Funcionalidades --

Inicio de sesión (Login)
Gestión de vehículos (consultar, crear, editar, eliminar)
Gestión de clientes
Gestión de rentas
Descarga de documentos PDF
Visualización de disponibilidad de vehículos

-- Tecnologías / Herramientas --

Figma (diseño UI/UX)
Java (implementación futura)
Google Fonts (tipografía Poppins)

-- Estructura del proyecto --

Assets (imágenes, tipografías, recursos)
Prototipo en Figma
Documentación

-- Instrucciones --

Abrir el prototipo en Figma.
Iniciar desde la pantalla de Login. (Iniciar sesion mediante Usuario y contraseña)
Navegar por el sistema usando el menú lateral. (Dashboard, Clientes, Vehiculos, Rentas, Locales)
Dashboard (Permite consultar informacion del sistema, como total de vehiculos, los disponibles, rentados, rendimiento, etc.)
Clientes(Crear, modificar, eliminar clientes, etc.)
Vehiculos(Ver los vehiculos dentro del sistema, su disponibilidad, estado, informacion importante, y realizar otras tareas)
Rentas (Permite agregar y crear rentas para clientes, buscar rentas, editarlas, eliminarlas, etc)
Establecimiento (Permite verificar los distintos locales de la compañia, asi como crear puntos de establecimientos y seleccionarlos para el calculo de distancias entre los distintos)
